## Original contributors and distribution scope

The repository credits **Adrian Bao, Mauricio Herrera, Trey Bryant and Tim Lukau**. Original Java character files contain all four author names; early commits also document team participation. Searches of tracked license/notice files, school source/documentation, current README and preserved tag found no project-wide redistribution license or explicit individual contribution grants. The only included license notice file concerns the runtime dependencies; those notices do not license the team's project.

The browser code is a separately authored TypeScript continuation, but that does not establish that the game is free of team contributions: it deliberately retains the school roster/roles, gameplay structure, map identities, acid coordinates and standalone content behavior, alongside historical attribution. Source language replacement and raster exclusion do not decide the legal ownership of that material. Contributor confirmation or appropriate legal review is advisable for the intended public browser-game and source redistribution scope. No claim is made that every mechanic is separately protectable, or that a particular contribution belongs exclusively to any one person.

Two decisions remain distinct: **distributing the Expedition-only game** and **continuing to expose preserved school code/assets/docs in the public repository**. The clean game package excludes those images; cloning/browsing repository history still exposes them. [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) distinguishes viewing/forking public repositories from broader license permissions. Neither public visibility nor attribution establishes the missing redistribution scope, and contributor consent would not supply rights to third-party assets they do not own. The owner should settle the intended preservation/public-repository approach separately. No assets, history, visibility, license or collaborators' repositories were changed.
